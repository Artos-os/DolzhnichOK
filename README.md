# ДолжничОК

Учебный прототип сервиса для записи студентов на пересдачи. Проект использует стек из согласованной схемы: .NET 10, ASP.NET Core 10, Blazor Interactive Server, PostgreSQL 17, EF Core 10, Npgsql и ASP.NET Core Identity.

## Состояние проекта

- В Visual Studio откройте `DolzhnikOk.slnx`.
- Вход `/`, регистрация студента `/registratsiya` и кабинеты `/student` и `/prepodavatel` работают с Identity и PostgreSQL.
- Студент ищет и фильтрует окна, записывается, отменяет запись до дедлайна (или до начала, если дедлайн не задан), видит свои записи, комментарии и уведомления.
- Преподаватель создаёт, изменяет, закрывает и отменяет свои окна, просматривает участников и отвечает на комментарии. Изменения окна и отмена отправляют уведомления записанным студентам.
- Проверка свободных мест выполняется в сериализуемой транзакции; уникальный индекс запрещает повторную активную запись одного студента на окно.
- Учётные записи студентов создаются через форму регистрации. Первый преподаватель задаётся конфигурацией при первоначальной настройке; роли и справочники создаются при запуске приложения.
- Автоматизированные тесты в проект пока не добавлены.

## Первый запуск

Нужны .NET 10 SDK и работающий PostgreSQL. Docker не обязателен. В этой конфигурации проект подключается к PostgreSQL на `localhost:5433`; при запуске в Development он автоматически применяет миграции и создаёт базовые роли и справочники.

Для локального PostgreSQL создайте базу `dolzhnikok` и роль `dolzhnikok` с паролем `dolzhnikok_dev_only` либо настройте строку подключения ниже под свои учётные данные. Если меняете пароль, задайте его через User Secrets:

```powershell
dotnet user-secrets set "ConnectionStrings:DefaultConnection" "Host=localhost;Port=5433;Database=dolzhnikok;Username=dolzhnikok;Password=ваш-пароль"
```

Перед первым запуском задайте данные первого преподавателя через User Secrets из папки проекта. Пароль задавайте отдельным секретом и используйте уникальное значение:

```powershell
dotnet user-secrets set "Bootstrap:Teacher:UserName" "имя_входа"
dotnet user-secrets set "Bootstrap:Teacher:Email" "преподаватель@example.org"
dotnet user-secrets set "Bootstrap:Teacher:FullName" "Фамилия Имя Отчество"
dotnet user-secrets set "Bootstrap:Teacher:Password" "сложный-уникальный-пароль"
```

Запустите проект клавишей **F5** или **Ctrl+F5**. При первом старте приложение создаст таблицы, роли `Student` и `Teacher`, кафедру, учебную группу, предмет и аудиторию. Названия по умолчанию — «Общая кафедра», «Общая группа», «Без указания предмета» и «101». Их можно переопределить ключами `Bootstrap:Department`, `Bootstrap:Group`, `Bootstrap:Subject` и `Bootstrap:Classroom` до первого запуска. Студенты регистрируются самостоятельно и выбирают учебную группу.

Docker Compose оставлен как альтернативный способ запустить PostgreSQL. Для него нужны Docker Desktop и файл `.env`, скопированный из `.env.example`; опубликованный порт базы — `5433`.

Для локальной разработки `.env.example` использует пароль `dolzhnikok_dev_only`. Не используйте его для реальных данных или при публикации приложения.

Чтобы остановить контейнер, в терминале Visual Studio выполните `docker compose down`. Данные БД останутся в Docker volume. Команда `docker compose down -v` удаляет этот volume вместе с данными.

## Структура данных

- `Models/ApplicationUser.cs` — пользователь Identity с целочисленным ключом и флагом активности.
- `Models/StudentProfile.cs`, `TeacherProfile.cs`, `StudentGroup.cs`, `Department.cs`, `Subject.cs`, `Classroom.cs` — профили и справочники.
- `Models/ResitSession.cs`, `Booking.cs`, `Comment.cs`, `Notification.cs` — пересдачи и связанные с ними данные.
- `Data/AppDbContext.cs` — связи, уникальные индексы и ограничения целостности.
- `Migrations/` — начальная миграция схемы БД.
- `docker-compose.yml` — PostgreSQL 17 с постоянным Docker volume.

При отмене окна активные записи помечаются отменёнными, а уведомления сохраняются в БД и отображаются в кабинете студента. Канал уведомлений в базовой версии — внутри приложения; отправка электронной почты или push-уведомлений не настроена.

## Страницы приложения

- `Components/Pages/Home.razor` — вход с проверкой учётной записи и роли.
- `Components/Pages/StudentRegistration.razor` — регистрация пользователя с ролью студента.
- `Components/Pages/Student.razor` — поиск окон, запись, отмена и комментарии.
- `Components/Pages/Teacher.razor` — управление расписанием, списком участников и комментариями.
- `Data/BootstrapInitializer.cs` — роли, базовые справочники и первоначальная учётная запись преподавателя.
- `Program.cs` — обработчики входа, выхода и регистрации, защита antiforgery, регистрация Identity, EF Core и Blazor.
